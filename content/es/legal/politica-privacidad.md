Este sitio web es informativo y **no incluye formularios, registro de usuarios ni sistemas de comentarios**. Los únicos datos personales que se pueden tratar son los que usted facilita voluntariamente cuando se pone en contacto con el titular:

No se utilizan estos datos para enviar comunicaciones comerciales ni se elaboran perfiles.

La base legal para el tratamiento es el consentimiento del interesado, que otorga al enviar su consulta, y, cuando proceda, el interés legítimo del titular en atender las comunicaciones recibidas.

Los datos se conservarán durante el tiempo necesario para atender su solicitud y, después, durante los plazos legalmente exigibles. Cuando dejen de ser necesarios, se suprimirán con medidas de seguridad adecuadas.

No se ceden datos personales a terceros, salvo obligación legal. El sitio web está alojado en LinuxBCN.com, que presta el servicio de alojamiento y actúa como encargado del tratamiento.

Algunas páginas pueden **incrustar contenido de terceros** (por ejemplo, reproductores de YouTube o Spotify). Al cargarse, estos servicios pueden recoger datos sobre usted y utilizar cookies o tecnologías similares, de acuerdo con sus propias políticas. Consulte el apartado "Contenido incrustado de terceros" y la [política de cookies](/es/legal/politica-cookies/).

## Analítica

Este sitio web utiliza **GoatCounter**, un servicio de analítica web respetuoso con la privacidad. GoatCounter **no utiliza cookies**, no crea perfiles y no almacena direcciones IP ni otros datos que permitan identificar a las personas; únicamente ofrece estadísticas agregadas y anónimas sobre las visitas (páginas vistas, origen aproximado, navegador). Por este motivo el sitio no muestra ningún báner de consentimiento de cookies.

## Contenido incrustado de terceros

Algunas páginas pueden incluir contenido incrustado (por ejemplo, reproductores de vídeo de YouTube o de música de Spotify). El contenido incrustado de otras webs se comporta exactamente igual que si usted hubiera visitado directamente esa otra web: esas webs pueden recopilar datos sobre usted, utilizar cookies e incrustar seguimiento de terceros.

El titular no controla estos servicios; le recomendamos consultar sus propias políticas de privacidad.
